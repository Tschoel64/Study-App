# Einteilung der Stoffe

## Reinstoffe
Ein Reinstoff besteht aus nur **einer Teilchensorte**.

- **Elemente** — nur eine Atomsorte
  - Metalle, z. B. Fe (Eisen), Cu (Kupfer)
  - Nichtmetalle, z. B. O (Sauerstoff), H (Wasserstoff)
- **Verbindungen** — mindestens zwei verschiedene Atomsorten
  - Salze — aus Ionen, z. B. NaCl
  - Molekulare Stoffe — aus Molekülen, z. B. H₂O, CO₂

## Stoffgemische
Ein Stoffgemisch enthält mindestens **zwei verschiedene Teilchensorten**.

- **Homogenes Gemisch** — einheitlich, Bestandteile nicht erkennbar
  - Lösung: Lösungsmittel + gelöster Stoff
  - Legierung: mindestens zwei Metalle (oder Metall + weitere Stoffe)
- **Heterogenes Gemisch** — uneinheitlich, mehrere Phasen erkennbar
  - Suspension: fest in flüssig
  - Emulsion: flüssig in flüssig
  - Rauch: fest in gasförmig
  - Nebel: flüssig in gasförmig

## Namensendungen anorganischer Verbindungen
| Endung | Bedeutung |
|---|---|
| -chlorid | Verbindung mit Chlor |
| -sulfid | Verbindung mit Schwefel |
| -sulfat | Salz der Schwefelsäure, $SO_4^{2-}$ |
| -nitrat | Salz der Salpetersäure, $NO_3^-$ |
| -carbonat | Salz der Kohlensäure, $CO_3^{2-}$ |
| -hydroxid | enthält $OH^-$-Ionen |

## Edelgasregel
Atome streben eine vollbesetzte Valenzschale an (**Edelgaskonfiguration**) — das ist die treibende Kraft hinter fast allen chemischen Bindungen.
